# 1C UZ Pro Academy — Professional Interactive Laboratory

Bu loyiha 1C: Buxgalteriya uchun **web-based o‘quv simulyatori**. Maqsad — foydalanuvchi real 1C serveriga ulanmasdan, 1Cdagi navigatsiya va asosiy buxgalteriya oqimini mashq qilishi:

**Раздел → Справочник → Документ → Провести → Дт/Кт → Регистры → Отчеты**

## Ishga tushirish

`index.html` ni brauzerda oching yoki GitHub Pages'ga joylang.

## Muhim

Bu **haqiqiy 1C konfiguratsiyasi emas**. 1Cning ichki konfiguratori, server, metadata va real registr mexanizmini browserda 100% ko‘chirish mumkin emas. Ushbu loyiha uning o‘quv uchun interaktiv modelini beradi.
